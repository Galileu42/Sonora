# Sonora

Aplicativo para Windows que baixa e converte áudio e vídeo do YouTube.
Tem fila persistente, lista de formatos por link e atualização automática pelo GitHub.

## Instalação

1. Baixe `Sonora_Windows.zip` em [Releases](https://github.com/Galileu42/Sonora/releases).
2. Extraia o ZIP inteiro e abra `Abrir_Sonora.cmd`.
3. A primeira abertura requer Python 3.10 ou superior, com Tcl/Tk, e internet.

A fila e o histórico ficam no perfil do Windows. Na janela **Atualizações**,
confira se o repositório está definido como `Galileu42/Sonora`.
O aplicativo instala versões baixadas ao fechar.

Consulte [LEIA-ME.txt](Sonora/LEIA-ME.txt) para ver os formatos, atalhos e instruções.
